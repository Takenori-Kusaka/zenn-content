### 序論：本章が扱う範囲

本章は、技術革新が社会構造を変化させる機序を、技術史および経済学の研究に基づいて整理します。あわせて、本書が第Ⅰ部Cで扱う主要な転換点を一覧として提示します。

本文は、既存研究が何を主張し、何を測定したかという事実の記述に限定します。解釈は章末で扱います。

### 1. 汎用技術という概念

すべての技術革新が社会構造を変えるわけではありません。多くの技術は、特定の用途に留まります。

経済学者ティモシー・ブレスナハンとマヌエル・トラジテンバーグは、一部の技術が持つ特別な性質を定式化しました [ [ 112 ] ](https://www.nber.org/papers/w4148) 。彼らはこれを「汎用技術」と呼びます。

その定義によれば、汎用技術は次の3つの性質を備えます。

第一に、広範な適用可能性です。単一の産業ではなく、多数の産業で利用されます。

第二に、時間を通じた改良です。導入後も性能が継続的に向上します。

第三に、補完的な革新の誘発です。その技術の存在が、他の領域における新たな発明を促します。

この枠組みによれば、蒸気機関、電力、そして情報技術は、いずれも汎用技術に該当します。

### 2. 導入から効果発現までの遅延

汎用技術の導入が、直ちに生産性の向上として現れるとは限りません。

経済史家ポール・デイヴィッドは、電力の事例を分析しました [ [ 113 ] ](https://www.jstor.org/stable/2006600) 。

彼の指摘は次のとおりです。電動機が工場に導入された当初、生産性の顕著な向上は観測されませんでした。当初の導入方法が、既存の蒸気機関を電動機に置き換えるだけのものであったためです。

従来の工場は、単一の動力源から軸とベルトを介して各機械へ動力を伝達する構造でした。この構造では、機械の配置は動力伝達の都合によって規定されます。

生産性の向上が現れたのは、各機械に個別の電動機を配置し、工場のレイアウトを作業の流れに沿って再設計した後でした。この再設計には、既存設備の更新と作業方法の変更を要します。デイヴィッドの分析によれば、この移行に数十年を要しました。

この事例が示すのは、技術の効果が、技術そのものではなく、それに合わせた組織の再設計によって発現するという点です。

### 3. 普及の過程

社会学者エヴェリット・ロジャーズは、新技術の採用が時間とともにどう広がるかを分析しました [ [ 114 ] ](https://openlibrary.org/works/OL718011W) 。

その研究は、採用者を採用時期によって分類し、累積採用率がS字型の曲線を描くことを示しています。初期は緩やかで、中期に急速となり、後期は再び緩やかになる形状です。

この研究はまた、採用の速さを規定する要因も整理しました。既存方式に対する相対的な優位、既存の価値観との適合性、複雑さ、試行の容易さ、そして結果の観察可能性です。

### 4. 技術と資本の循環

経済学者カルロタ・ペレスは、技術革新と金融資本の関係を長期の循環として分析しました [ [ 115 ] ](https://openlibrary.org/works/OL224128W) 。

その枠組みでは、各技術革命は2つの局面を経ます。前半は導入局面であり、金融資本が新技術へ集中的に投下されます。この局面では、投機的な過熱と、その後の調整が生じます。後半は展開局面であり、技術が社会全体へ浸透し、制度がそれに適合します。

この枠組みは、18世紀後半以降の複数の技術革命に適用されています。

### 🗺️ 図：技術が社会構造を変える経路

技術そのものではなく、何を経由して構造が変わるかを、4本の帯の時間配置として示します。

![技術が社会構造を変える4つの効果の時間配置。効果1作業の代替、効果2組織の再設計、効果3職能の再編、効果4制度の変更が、開始時期をずらしながら重なって現れる](/images/sovereign-resilience-blueprint/four-effects.png)

#### 図の読み方

この図が示しているのは、技術の社会的な影響が、4段階を経て現れるという構造です。上から下へ並ぶ4本の帯は、それぞれの効果が現れる期間を表します。帯の開始位置が右へずれていくことが、段階の順序と速度差にあたります。

効果1は、技術が直接もたらす代替です。ここまでは、技術の性能によって説明できます。

効果2は、デイヴィッドの分析が示した段階にあたります。技術の効果が発現するには、組織の側での再設計が必要です。この再設計には時間と費用がかかるため、効果1と効果2の間には遅延が生じます。

効果3が、社会的な摩擦が最も顕在化する段階です。組織が再設計されると、必要とされる技能の構成が変わります。従来の技能を持つ層は、その技能の価値低下に直面します。

効果4は、制度の追随です。教育課程、資格制度、労働法規、そして分配の仕組みが、新しい職能構成に適合するよう変更されます。この段階は、最も時間がかかります。

本書にとって重要なのは、この4段階の速度差です。各効果の所要期間は事例によって異なります。デイヴィッドの分析では、電化が生産性の統計に現れるまでに約40年を要しました [ [ 113 ] ](https://www.jstor.org/stable/2006600) 。第Ⅰ部C-12で扱うアレンの分析では、機械化から実質賃金の上昇まで約半世紀を要しています [ [ 116 ] ](https://doi.org/10.1016/j.eeh.2009.04.004) 。効果1から効果4へ進むほど所要期間が長くなるという傾向は、これらの事例に基づく本書の作業仮説です。

この速度差の期間に、効果3で価値低下に直面した層が存在する一方、効果4の制度的な調整はまだ完了していません。この期間が、社会的な緊張が高まる局面です。

第Ⅰ部Cの各章では、過去の転換点においてこの期間に何が起きたかを記述します。第Ⅱ部および第Ⅲ部では、現在進行中の転換が、この4段階のどこに位置するかを評価します。

### 現代社会構造への射程と本質（本章のまとめ）

本セクションは、著者による解釈です。前節までの記述とは区別して読んでください。

1.  **現代社会構造の原点**

    現在の職能構成、教育課程、そして労働法規は、いずれも20世紀の技術条件に適合するよう設計されました。効果4の段階を経て確立した制度です。

    したがって、これらの制度が現在の技術条件に対して最適である保証はありません。制度は、前の転換点に適合しています。

2.  **歴史的事実の本質**

    本章から抽出できるのは、技術革新の影響が技術の性能ではなく、組織と制度の追随速度によって規定されるという点です。

    この認識は、現在の生成AIをめぐる議論に適用できます。この技術がどの程度の能力を持つかという問いと、社会がどう変化するかという問いは、直接には結びつきません。後者を規定するのは、組織の再設計速度と制度の追随速度です。

3.  **現代社会の現状と課題**

    第Ⅲ部では、この4段階モデルを用いて、生成AIと量子計算の影響を時間軸上に配置します。

    そこでの主要な論点は、効果3と効果4の間の期間がどれだけ長くなるかです。この期間が長いほど、価値低下に直面した層と、制度的な調整との乖離が拡大します。第Ⅰ部A-8で整理した崩壊の早期警戒指標に照らせば、この乖離は、正統性への疑義が発生する条件に該当します。
