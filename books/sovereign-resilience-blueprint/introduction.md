### 1. なぜ、いま未来予測が必要なのか

現代社会は、複数の構造的な限界と技術的な断絶とが同時に訪れる局面にあります。

第一に、人口動態の限界です。日本の総人口は2008年をピークとして減少局面に入りました [ [ 61 ] ](https://www.stat.go.jp/data/jinsui/index.html) 。国の公式な人口推計を担う社人研による将来推計では、2070年の総人口は8,700万人、高齢化率は38.7%に達すると見込まれています [ [ 62 ] ](https://www.ipss.go.jp/pp-zenkoku/j/zenkoku2023/pp_zenkoku2023.asp) 。これは予測ではなく、すでに生まれた世代の年齢構成から導かれる、ほぼ確定した与件です。

第二に、技術的な断絶です。大規模言語モデルを中心とする生成AIは、知的労働の一部について生産性を有意に変化させる水準に到達したことが観測されています [ [ 118 ] ](https://www.nber.org/papers/w31161) 。量子計算については、誤り訂正の基盤技術が実験的に実証される段階に入りました [ [ 160 ] ](https://www.nature.com/articles/s41586-024-08449-y) 。既存の暗号方式については、量子計算に耐性を持つ暗号方式への移行が標準化を伴って始まっています [ [ 165 ] ](https://csrc.nist.gov/projects/post-quantum-cryptography) 。これらは、産業構造と職能構成とを再編する規模の変化です。

第三に、国際秩序の再編です。ウクライナおよび中東における武力紛争は、発電所、送電網、港湾、海峡といった民生インフラそのものが攻撃目標として選択される事例を示しました [ [ 148 ] ](https://www.iea.org/reports/ukraines-energy-security-and-the-coming-winter) 。

これら3つの変化は、いずれも個別の事件ではありません。社会システムの前提条件そのものを書き換える種類の外部入力です。したがって、「何が起こりうるか」を事前に構造化しておくことには、実務上の意味があります。

### 2. 本書の設計思想：砂時計アーキテクチャ

本書は、過去・現在・未来を1つの推論の連鎖として扱います。その構造を、砂時計になぞらえて設計しました。

砂時計の上半分は「過去」です。ここには、国家の興亡、統治思想（主義）の変遷、科学技術の革新、戦争の様式変化という、膨大な事象が広がっています。それらはすべて、時間の経過とともに1点へと収束していきます。

砂時計のくびれは「現在」です。ここは面積を持たない1点であり、過去のすべての帰結が集約される場所です。同時にこの1点には、外部から放射状に入力が加わります。国際紛争、自国優先主義の台頭、生成AI、量子計算といった、社会構造を変質させる外部要因です。

砂時計の下半分は「未来」です。1点に集約された条件と、そこに加わる外部入力とが相互作用し、複数の可能性へと放射状に広がっていきます。

この構造は、本書の目次そのものでもあります。第0章では、この全体像を図として提示します。

### 3. 記述規範：事実と推論の厳格な分離

未来予測の価値は、その土台となる事実の精度に依存します。事実の整理が不正確であれば、そこから導かれる推論は無価値になります。そこで本書は、以下の3つの規範を全編で適用します。

**規範1：過去の記述は、事実のみで構成します**

[第Ⅰ部](01_sovereign-state-os)（過去）の本文では、時系列に沿った客観的事実のみを記述します。現代社会との類比、教訓、著者の解釈は、本文に混入させません。それらはすべて、各章末尾の「現代社会構造への射程と本質」という独立したセクションに隔離します。各章の図に付す「図の読み方」は、図の構造を説明する箇所であり、事実の要約に加えて著者による整理を含みます。読者は、事実の記述と解釈の記述とを、視覚的に区別しながら読み進めることができます。

**規範2：出典は、当該記述の直後にインラインで示します**

歴史的事実、既存の社会科学理論、そして現行の技術仕様については、その記述の文末に一次資料への外部リンクを直接配置します。章末の参考文献一覧への相対リンクは使用しません。読者は、記述と根拠とを1クリックで往復できます。

**規範3：情報源は、一次資料と公的資料に限定します**

歴史的事実については、原典テキスト、学術的に確立した研究、そして公的アーカイブを参照します。各国の現状については、当該政府が公表している公式文書、統計、白書を参照します。個人のブログ、匿名の言説、および出典の追跡が不可能な二次情報は、根拠として採用しません。

未来に関する記述については、それが推論であることを明示します。前提条件、推論の経路、および外れる条件を併記します。断定的な予言は行いません。

### 4. 本書の構成

本書は、次の5部と総括で構成されます。あわせて、3つの付録を別の記事として公開しています。

*   **[第Ⅰ部](01_sovereign-state-os)：過去 ―― 文明システムの興亡（事実の整理）**
    4つの系列を、それぞれ時系列で整理します。Aは国家の興亡、Bは統治思想の変遷、Cは科学技術の革新、Dは戦争の様式変化です。なお本書は、統治の仕組みを計算機の基本ソフトになぞらえて「統治OS」と呼びます。その定義は[第Ⅰ部B-1](isms-overview)で示します。組織が腐敗し、外部衝撃に対応できなくなり、限界点に達する過程を、複数の文明から抽出します。
*   **[第Ⅱ部](japan-current-state)：現在 ―― くびれに集中する外部入力（現状の整理）**
    Aでは日本、アメリカ、EU、中国について、体制、運営方式、課題を公式資料から整理します。Bでは進行中の武力紛争を分析します。Cでは技術と情報の環境を、Dでは物理的な脆弱性を扱います。
*   **[第Ⅲ部](future-method)：未来 ―― 3年から20年の推論**
    まず予測の方法を開示し、外部要因となるイベントリスクを定義します。そのうえで、ベースライン、楽観、悲観の3つのシナリオを提示し、分岐条件と早期警戒指標を明示します。
*   **[第Ⅳ部](implication-state)：帰結 ―― 国家・社会・組織・個人は何を期待されるか**
    推論された未来において、国家、地域社会、企業、個人のそれぞれに求められる機能がどう変化するかを論じます。
*   **[第Ⅴ部](42_taoist-wu-wei-non-action)：設計 ―― 自律分散型システムの実装**
    第Ⅳ部で導かれた要請に対し、既存の制度理論と実在する技術とを接続した具体的な設計を提示します。
*   **総括**
    第Ⅰ部から第Ⅳ部までを1本の推論として接続し、どの前提からどの結論が導かれるかを明示します。第Ⅴ部の設計提案が、この推論に対してどの位置にあるかも示します。あわせて、本書が答えていない問いを列挙します。
*   **[付録A：技術者の職責](https://zenn.dev/takenori_kusaka/articles/srb-appendix-engineer-role)**
    以上の推論を踏まえ、技術者という職能が将来社会において何を担うのかを検討します。
*   **[付録B：用語集](https://zenn.dev/takenori_kusaka/articles/srb-appendix-glossary)**
    本書が特定の意味で用いる専門用語を、初出の章とともに定義します。
*   **[付録C：参考文献](https://zenn.dev/takenori_kusaka/articles/srb-appendix-bibliography)**
    本書が参照したすべての一次資料および公的資料を、系統的に一覧します。

付録は本編の分量の制約により、別の記事として公開しています。用語集と参考文献は、本編を読み進めながら別のタブで参照できます。

### 5. 想定する読者

本書は、次のような読者を想定しています。

自らの職能が今後どう変質するのかを構造的に理解したい技術者。地域や組織の意思決定に関与し、10年から20年の時間軸で判断の前提を整理する必要のある実務者。そして、断片的な言説ではなく、検証可能な事実から未来を考えたいと望むすべての読者です。

本書は、特定の結論を受け入れることを求めません。事実の整理と推論の経路を開示し、読者が自身の判断を組み立てるための材料を提供することを目的とします。
