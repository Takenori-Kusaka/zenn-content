### 序論：本章が扱う範囲

本章は、統治機構の劣化と崩壊について、これまでにどのような分析枠組みが提示され、どの指標が測定されてきたかを整理します。

本章で記述するのは、著者の推測ではありません。特定の研究者が何を主張し、どのデータを用いたかという、研究史上の事実です。各枠組みには原典への直接リンクを付します。読者は、記述の妥当性をその場で検証できます。

なお本書は、これらの枠組みのいずれかが正しいという立場を採りません。複数の枠組みが共通して指し示している観測項目を抽出することが、本章の目的です。

### 1. イブン・ハルドゥーンの世代周期論（1377年）

北アフリカの歴史家イブン・ハルドゥーンは、著書『歴史序説』において、王朝の興亡を集団的な連帯意識の変化として記述しました [ [ 66 ] ](https://archive.org/details/muqaddimahintrod0001ibnk) 。

彼が用いた概念は「アサビーヤ」です。これは、集団の構成員が相互に負う義務感と、集団への同一化の強度を指します。

その記述によれば、王朝は概ね次の経過をたどります。建設期の世代は、過酷な環境で形成された強い連帯意識を持ち、それによって権力を獲得します。第2世代は、建設者を直接知っており、その規範を継承します。第3世代は、確立された制度の内側で育ち、連帯意識を規範として学習しますが、実感を伴いません。第4世代は、権力の由来を知らず、制度が提供する利益のみを享受します。

イブン・ハルドゥーンは、家系の威信が続く期間を最長で4世代とする一方、王朝の寿命を3世代、およそ120年と見積もりました。なお彼は別の箇所で、王朝の推移を5段階に分けて記述しています。彼が観察の対象としたのは、北アフリカとイベリア半島の諸王朝です。

### 2. ギボンのローマ衰亡史（1776年から1789年）

エドワード・ギボンは、ローマ帝国の衰亡を6巻にわたって記述しました [ [ 23 ] ](https://www.gutenberg.org/ebooks/25717) 。

ギボンが提示した要因は複合的です。軍事負担の増大、属州統治の費用、市民の軍役忌避、傭兵への依存、宗教的な価値観の変化、そして帝位継承の不安定化が挙げられています。

ギボンの記述で特筆すべきは、崩壊を単一の外部要因に帰していない点です。彼は、帝国が拡大の過程で獲得した規模そのものが、維持費用を通じて負担へ転化したと論じました。

### 3. テインターの限界収益逓減モデル（1988年）

人類学者ジョセフ・テインターは、複数の文明の崩壊事例を比較し、共通する構造を提示しました [ [ 68 ] ](https://openlibrary.org/works/OL4741769W) 。

テインターの枠組みは、社会の複雑性を投資として扱います。官僚機構の拡大、専門職の分化、情報処理階層の追加。これらはいずれも、問題解決能力を高めるための投資です。

彼が指摘したのは、この投資に対する収益が逓減するという点です。初期の複雑化は、大きな問題解決の利得をもたらします。しかし複雑性が一定水準を超えると、追加の複雑化がもたらす利得は、その維持費用を下回るようになります。

この段階に達した社会は、外部衝撃に対する余力を失います。テインターは、崩壊とは災厄ではなく、維持費用に見合わなくなった複雑性を放棄する経済的な調整である、と定式化しました。

### 4. ターチンらの構造人口学（2009年）

ピーター・ターチンとセルゲイ・ネフェドフは、複数の社会について長期の定量データを収集し、周期的な変動の存在を検証しました [ [ 69 ] ](https://doi.org/10.1515/9781400830688) 。

この研究が測定対象としたのは、主に次の3つの変数です。

第一に、人口と資源の比率です。人口が資源の扶養能力に接近すると、実質賃金が低下します。

第二に、エリート層の規模です。エリートの再生産率が、エリートが占めうる地位の数を上回る状態を、この研究は「エリート過剰生産」と呼びます。この状態では、地位を得られなかった層が、既存秩序に対する異議申し立ての担い手となります。

第三に、国家財政の健全性です。歳入に対する歳出の比率、および債務の水準が指標となります。

この研究の主張は、これら3つの変数が同時に悪化した局面において、政治的な不安定性が集中して発生したというものです。

### 5. 制度の性質に関する研究（2004年）

経済学者ダロン・アセモグルらは、長期の経済成長を規定する要因として、制度の性質を挙げました [ [ 70 ] ](https://www.nber.org/papers/w10481) 。

この研究は、制度を2つの類型に区別します。1つは、広い層に財産権と参加機会を保障する類型です。もう1つは、少数の層が資源を吸い上げる構造を持つ類型です。

後者の類型においては、支配層が技術革新を抑制する動機を持ちます。革新は既存の権力配分を変化させるためです。この抑制が、外部環境の変化に対する適応能力の低下として現れる、というのがこの研究の論旨です。

### 🗺️ 図：5つの枠組みが共通して指す観測項目

各研究が測定した変数を、余力の曲線に沿って配置します。

#### 図の読み方

この図は、縦軸に余力、横軸に時間を取り、5つの研究が用いた異なる語彙を共通の時間軸上に4つの段階として配置したものです。曲線は余力が段階を追って逓減する経過を示し、破線は段階の区切り、右下の赤い矢印は外部衝撃の到来を示します。

イブン・ハルドゥーンが「アサビーヤの減衰」と呼んだ現象は、段階1から段階2への移行に対応します。ギボンが挙げた規模の維持費用への転化と、テインターの「限界収益の逓減」は、段階2から段階3への移行を説明します。ターチンらの「エリート過剰生産」と「実質賃金の低下」は、段階3において同時に観測される指標です。アセモグルらが指摘した収奪的な制度による革新の抑制も、段階3において適応能力の低下として現れます。

重要なのは、段階4です。ここで発生するのは、資源の枯渇ではなく、軍事的敗北でもありません。統治の正統性が争点化するという、性質の異なる事象です。

前章までに記述した3つの事例は、この構造と対応づけられます。ローマの事例は、本図の段階2から段階3（維持費用の増大と徴税基盤の縮小）に対応します。段階4に相当する正統性の争点化は、3世紀の皇帝位の不安定化として先行して観測されます。オスマン帝国では、統治正統性の基礎そのものが、王朝への帰属から民族への帰属へ置き換わりました。江戸幕府では、条約の勅許を得られなかったことによって、幕府が最終決定権を持つという前提が否定されました。

したがって、崩壊の早期警戒指標として観測すべきは、経済指標そのものではありません。経済指標の悪化が、統治の正統性に関する公然の異議へ転化するかどうか。この転化の有無が、段階3と段階4とを分けます。

### 現代社会構造への射程と本質（本章のまとめ）

本セクションは、著者による解釈です。前節までの記述とは区別して読んでください。

1.  **現代社会構造の原点**

    現代の国家は、いずれも段階2の特徴を強く備えています。行政機構は高度に分化し、規制の体系は増大を続けています。この複雑化は、それぞれの時点では合理的な問題解決の手段として導入されました。

    しかしテインターの枠組みが示すのは、個々の複雑化が合理的であることと、複雑性の総量が持続可能であることとは、別の問題だという点です。ある行政手続の追加は、それ単体では正当化されます。その総和が維持費用として何を要求するかは、別途評価されなければなりません。

2.  **歴史的事実の本質**

    5つの研究が共通して指し示しているのは、次の構造です。組織の劣化は、単一の破局的事象としてではなく、余力の逓減として進行します。そして、余力を失った状態に外部衝撃が加わったとき、劣化は崩壊として顕在化します。

    したがって「何が起きたら限界点か」という問いへの回答は、外部衝撃の大きさではありません。同規模の衝撃に対して、以前は吸収できたものが吸収できなくなること。この応答特性の変化が、限界点の指標です。

3.  **現代社会の現状と課題**

    本章で抽出した観測項目は、[第Ⅱ部](japan-current-state)において、現在の日本および主要国に対して適用されます。具体的には、次の項目を公的統計から確認します。

    人口と資源の比率については、労働力人口と社会保障給付の比率。財政の健全性については、国債残高と歳入の比率。制度の複雑性については、行政手続と法令の総量。そして正統性については、選挙における投票率と、制度に対する信頼度の調査結果です。

    これらは、いずれも公表されている統計です。本書は、それらを本章の枠組みに沿って配置し、現在がどの段階に対応するのかを検討します。
